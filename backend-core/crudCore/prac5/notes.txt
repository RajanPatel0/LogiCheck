OFFSET pagination vs CURSOR / KEYSET pagination: Used In feeds / infinite scrolling / large datasets / activity logs / social timelines / transaction histories

1. OFFSET:

?page=100&limit=10
        ↓
skip = 990
        ↓
DB scans/skips previous rows
        ↓
return next 10


http://localhost:3000/api/products-offset?page=1&limit=10
    gets 1–10

then /api/products-offset?page=2&limit=10
    gets 11–20


    page = 2
    limit = 10

    skip = (2 - 1) × 10
        = 10


Actual Logic: to skip as of skip value passed

2. CURSOR

?cursor=990&limit=10
        ↓
WHERE id > 990
        ↓
ORDER BY id
        ↓
LIMIT 10
        ↓
return next 10

/api/products-cursor?limit=10
