Object-Relational Mapping (ORM)
    It's a programming technique that acts as a bridge between object-oriented programming (OOP) languages and relational databases. 
        Instead of writing raw SQL queries, we work with objects in our code, 
            and the ORM framework automatically translates these operations into SQL statements for the database.

Core Principles
    Entity Mapping: Classes in code map to database tables, attributes map to columns, and object instances map to rows.
    Relationship Mapping: Supports one-to-one, one-to-many, and many-to-many relationships, converting them into foreign keys and join tables.
    Data Type Mapping: Converts programming language data types to database-compatible types.
    Persistence: Ensures data remains stored in the database even after the application stops running.

Example: Prisma handles database operations, but the database system itself (PostgreSQL) is required.
